# Gold Path

Independent QA for companies and AI agencies running AI voice and chat agents.

This repository holds the static HTML/CSS/JS marketing landing page (`index.html`, `styles.css`, `script.js`).

## Local preview

Open `index.html` directly in a browser, or serve the directory locally:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
